1. Password Hashing (bcrypt) FLASK 3.11

Passwords are salted and hashed using bcrypt (12 rounds) before database write. Passwords never reside in plaintext.

# auth_service.py
hashed = bcrypt.hashpw(
  password.encode('utf-8'),
  bcrypt.gensalt(rounds=12)
)
is_valid = bcrypt.checkpw(entered, db_hash)
